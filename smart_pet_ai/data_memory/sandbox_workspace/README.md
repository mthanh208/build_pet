# PET AI SANDBOX WORKSPACE

This directory is the autonomous working home for Pet.

- `drop_here/` input files you give Pet
- `artifacts/` final generated or repaired files
- `runs/` isolated execution runs
- `reports/` diagnostic/test reports
- `scratch/` temporary working files
- `tools/` additional tools you add later
- `toolbox.py` lightweight agent toolbox
- `PET_SANDBOX_RULES.md` operating rules for autonomous code work
